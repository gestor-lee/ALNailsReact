# AL Nails Designers

Aplicativo de agendamento de serviços de manicure e pedicure, desenvolvido para facilitar a organização dos atendimentos, o gerenciamento de horários e a experiência das clientes.

## Sobre o projeto

O **AL Nails Designers** é uma aplicação desenvolvida para modernizar e facilitar o processo de agendamento de serviços de beleza.

O projeto busca oferecer praticidade às clientes e melhorar a organização administrativa dos atendimentos.

## Funcionalidades

- Agendamento de serviços.
- Consulta de horários disponíveis.
- Organização dos atendimentos.
- Gerenciamento administrativo.
- Cadastro e gerenciamento de serviços.
- Interface desenvolvida para facilitar a utilização.

## Tecnologias utilizadas

- React
- Vite
- JavaScript
- Tailwind CSS
- Firebase Authentication
- Cloud Firestore
- Firebase Storage

## Aplicativo

O AL Nails Designers também possui versão para dispositivos Android, publicada na Google Play Store.
